# ADR-0012: 本体のライセンスを Apache-2.0 から GPLv3-or-later へ変更する

- 状態: 承認
- 日付: 2026-08-09

---

## 背景

`CLAUDE.md` と `docs/licenses.md` §1 は、本体のライセンスを **Apache License 2.0** と定めていた。
ただし **`LICENSE` ファイルは存在せず**、GitHub 上でもライセンス未検出の状態が続いていた。
ソースにライセンスヘッダも入っていない。

GitHub 向けにドキュメントを整える際、**利用者から GPL への変更の指示があった。**

`docs/licenses.md:36` は「この判断は `CLAUDE.md` の決定事項である。変更するには ADR を書く」と
定めているため、本 ADR を書く。`CLAUDE.md` 停止条件 7（ライセンスの判断）にも該当するため、
実装前に停止して確認した。

### 権利関係の確認

`git log` の実測で、**著者は Silent Malachite 単独**（全 50 コミット）である。
第三者の著作物を取り込んでいないため、再ライセンスに他者の同意は要らない。

Apache-2.0 のコードを GPLv3 のプロジェクトへ取り込むことは一方向に許されているが、
**そもそも単独著者であるため、その論点は生じない。**

---

## 選択肢

GPL には両立性の観点で決定的な差があるため、版を分けて検討した。

### A. GPLv3 or later

> either version 3 of the License, or (at your option) any later version

### B. GPLv3 only

将来の版を自動適用しない。

### C. AGPLv3 or later

GPLv3 にネットワーク経由の利用に関する条項を追加したもの。

### D. GPLv2 only

**Qt の LGPLv3 と両立しない。**

---

## Qt との両立が版を決める

**本プロジェクトは Qt 6 を LGPL v3 で使い、動的リンクしている**（`docs/licenses.md` §2）。

| 選択 | Qt LGPLv3 との両立 | 根拠 |
|---|---|---|
| **A / B（GPLv3）** | **両立する** | LGPLv3 は GPLv3 での再配布を許可している |
| C（AGPLv3） | 両立する | 同上（AGPLv3 は GPLv3 と互換の運用が定められている） |
| **D（GPLv2 only）** | **両立しない** | LGPLv3 から GPLv3 への移行は可能だが、**GPLv2 へは下げられない** |

**D を選ぶと配布できなくなる。** 「GPL」という指示だけでは版が決まらないため、
推測せず利用者に確認した。

### C を採らない理由

**本アプリはネットワーク通信を一切行わない**（`CLAUDE.md` の絶対禁止事項）。
AGPL の追加条項は「ネットワーク越しに利用者と対話するプログラム」に働くため、
**本プロジェクトでは発動する場面が存在しない。**

条項が働かないライセンスを選ぶと、実効的な違いが無いまま派生物の作者に
制約と混乱を与えることになる。採らない。

---

## 決定

**A を採る。GNU General Public License version 3 or later とする。**

理由。

1. **Qt の LGPLv3 と両立する。** LGPLv3 §2 が GPLv3 での再配布を許可しているため、
   動的リンクの方針（`docs/licenses.md` §2.1）を変えずに済む。
2. **将来の版に追随できる。** `or later` を付けることで、GPL の次の版が出たときに
   再ライセンスの手続きを踏まずに済む。GPL では最も一般的な選択である。
3. **AGPL の条項は本プロジェクトでは働かない**（上記）。

---

## 帰結

### 変更したもの

| ファイル | 内容 |
|---|---|
| `LICENSE`（新規） | gnu.org の GPLv3 正本（674 行）をそのまま置く。**改変しない** |
| `docs/licenses.md` §1 | Apache-2.0 → GPLv3-or-later。Qt との両立根拠を追記 |
| `docs/licenses.md` §5 | **Phase 3 の制約が変わる**（下記） |
| `CLAUDE.md` | ライセンス行を更新 |
| `README.md` | ライセンス節と Qt についての説明 |
| `CONTRIBUTING.md` | 貢献が GPLv3-or-later で配布されることを明記 |

### Phase 3 の制約が緩む（副次的な効果）

`docs/licenses.md` §5 は、以前は次のように書いていた。

> GPL のみで提供されるライブラリをリンクすると本体の Apache-2.0 と両立しないため、
> ライセンスの確認を導入判断より先に行う。

**本体が GPLv3 になったことで、この非両立は解消する。**
HEIF / AVIF / JPEG XL / RAW / PSD の追加コーデックで **GPL のみで提供されるライブラリが
選べるようになった。**

ただし**確認そのものは引き続き必要である。** GPL と両立しないライセンス
（独占的ライセンス、GPL 非互換の条項を持つもの）は依然として使えない。
`docs/phases.md` §4 Phase 3 の「導入前に `docs/licenses.md` を更新する」は変更しない。

### 変わらないもの

- **Qt は LGPLv3 で動的リンクのみ。** この判断は維持する（`docs/licenses.md` §2.1）
- **Catch2 は BSL-1.0 でテストのみ。** 成果物に含まれない
- **Phase 4 の第三者ライセンス文の同梱義務**（`docs/licenses.md` §4）

### 今回やらなかったこと

**ソースファイルへのライセンスヘッダの一括挿入。** 58 ファイルに及ぶため別タスクとする。
GPL は各ファイルへの告知を推奨しているが、義務ではない。
`LICENSE` と `README.md` での明示で現時点は足りる。

**未リリースであることに注意。** 配布物がまだ存在しないため、
この変更で影響を受ける既存の利用者はいない。
